# Panel

**A panel of AI specialists that reads your contract, in your language, and tells you what's wrong with it.**

Built for the Databricks "Building Intelligent Apps" Hackathon, APJ — Track 1 (Social Impact), May 2026.

- **Live app:** https://panel-7474659131504222.aws.databricksapps.com
- **Spec:** [`docs/spec.md`](docs/spec.md)
- **Demo script:** [`docs/demo-script.md`](docs/demo-script.md)

## What it does

A migrant worker pastes their employment contract, selects their mother tongue, and describes their situation in one sentence. Six specialist AI agents read the contract in parallel, **publicly disagree** where their views diverge, then run a Round 2 rebuttal turn — before synthesising a single recommendation in the worker's L1.

The disagreement is the product. Single-agent contract analyzers are commodity. A panel that visibly debates its own conclusions is what makes the output trustworthy.

### The six agents

| Agent | Role |
|---|---|
| **Lawyer** | Maps each clause to the destination-country labor code. Verdict per clause: lawful / gray-area / unlawful, with statute citation. |
| **Translator** | Renders the contract + findings in the worker's mother tongue. Flags semantic ambiguities in the translation itself. |
| **Regulator** | Scores against ILO C97/C143/C181/C189/C190 + ASEAN Rights-Based Standard. |
| **Peer Advocate** | Pattern-matches each clause against an anonymised archive of past cases. |
| **Triage** | Detects ILO trafficking indicators. Routes urgent cases to embassy/NGO. |
| **Negotiator** | Coaches the worker for the pre-signing conversation: priority pushback, questions to ask in L1 + EN, red-flag recruiter responses, walk-away threshold. |

## Deploy

```bash
./scripts/build_and_deploy.sh
```

This runs the Vite build, copies the static bundle into `app/static/`, validates the Databricks bundle, deploys, and restarts the app.

## Run locally

The Streamlit fallback (limited features, no Lakebase/Genie):

```bash
cd ~/panel
.venv/bin/streamlit run app/streamlit_app.py
```

The full FastAPI server + cinematic frontend (requires the `panel-v2/` repo and a Vite dev server):

```bash
# Backend
PANEL_LLM_PROVIDER=mock uvicorn api.server:app --reload --app-dir app

# Frontend (separate terminal, in panel-v2/)
npm run dev
```

The Vite dev server proxies `/api/*` to `http://127.0.0.1:8000`.

## LLM provider — swappable

| Provider | Env var | Notes |
|---|---|---|
| `mosaic` (production default) | `PANEL_LLM_PROVIDER=mosaic` | Mosaic AI Foundation Models (qwen3-next-80b, llama-3-3-70b) |
| `anthropic` | `ANTHROPIC_API_KEY=sk-ant-...` | Claude family |
| `openai` / `gemini` / `lmstudio` / `claude_cli` / `mock` | Each behind its own env var | All routed through `app/providers.py` |

## Legal

Panel provides **informational guidance only**. It is not legal advice. Every output is paired with a disclaimer in the worker's L1. The Triage agent always surfaces at least one non-employer contact (embassy 24-h hotline, NGO, in-country legal aid).
